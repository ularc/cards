Using CARDS with BigData

BigData has had a network upgrade from 1GbE to 10GbE.

Global SSH configurations have been made so that users can utilize normal SSH commands (sftp, scp, rsync, etc.) using the target hostname of cards.rc.louisville.edu to automatically transfer data to CARDS over this connection.
