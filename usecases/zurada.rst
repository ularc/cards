Using CARDS with Zurada
-----------------------

The Zurada datatransfer node (``dt.rc.louisville.edu``) has a direct bonded 100GbE network connection to CARDS. Global SSH configurations have been made to automatically transfer to CARDS over this connection.

Global SSH configurations have been made so that users can utilize normal SSH commands (sftp, scp, rsync, etc.) using the hostname of ``cards`` or ``cards.rc.louisville.edu`` to automatically transfer data to CARDS over this connection.
